## Governing implementation rule

No agent or consequential capability may be implemented before its relevant specification is reviewed and approved. The complete book is not required before implementation; each module is added before that module is built.

## Current authority baseline

B-001 may read, analyze, prepare, coordinate, convene meetings, produce recommendations, and request approval. It may not deploy, publish externally, delete records, make financial commitments, change access controls, or execute strategic decisions without explicit Human CEO authorization.
