# P2-10 Review Platform Submission Checklist

Reviewed: 2026-09-03

## Capterra / GetApp

Owner-account action required:
1. Open the Capterra vendor listing flow.
2. Create or use the vendor account controlled by RYTHM.
3. Submit product name exactly as `RYTHM Company OS`.
4. Use `https://rythm-os.com` as the destination website.
5. Use the neutral third-person description from `docs/seo/review-platform-profile-pack.md`.
6. Identify the product as `Public Beta`; do not imply GA.
7. Link or reference public Demo, Pricing, Trust, Security and Integration information where the form permits.
8. Upload only real product UI screenshots; no stock images.
9. Do not create or solicit fabricated reviews. A genuine user review is required within the first calendar year if the beta profile is accepted.
10. Capture the submission confirmation and resulting public profile URL when available.

## TrustRadius

Owner-account action required:
1. Create/use the official vendor account.
2. Search for an existing RYTHM Company OS profile before requesting a new one.
3. If absent, request or create the vendor/product listing through the available vendor workflow.
4. Use the canonical profile pack.
5. Add pricing, demo, screenshots, security information and product video only when factual and available.
6. Record the public URL and publication status.

## G2

Do not submit while the product is explicitly `Public Beta`.
Re-check eligibility after General Availability.

## Closure rule

P2-10 can be classified as DONE only when at least one independent review/software-discovery platform has a public live RYTHM Company OS profile and the profile is recorded in `data/seo/review-platform-evidence.csv`. No review score or count may be recorded unless it is actually public on that platform.
