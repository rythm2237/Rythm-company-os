# Batch 4 Multi-Project UX Validation

## Must pass
- `/projects` renders an organization portfolio instead of a single hard-coded project.
- Project cards show project progress, status, stage, priority, target date, active agents, actions, decisions and meetings.
- Opening a project carries an explicit `project` identifier into the operating view.
- `/actions` can filter by project and keeps project context while selecting actions.
- New direct CEO actions can optionally be assigned to a project.
- Project Pulse still auto-opens for a new progress event and can also be reopened later from its persistent launcher.
- No change grants agent or external-action authority.
- No database migration is required.
