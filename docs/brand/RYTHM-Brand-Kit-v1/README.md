# RYTHM Company OS - Brand Kit v1.0

این بسته، نسخهٔ نهایی وکتور کانسپت «R ماژولار» است. نشان بر چهار مفهوم بنا شده است: محور اختیار انسانی، سازمان ماژولار عامل‌های هوش مصنوعی، نقطهٔ تصمیم کنترل‌شده و حرکت از تصمیم به اجرا.

## فایل‌های اصلی

- `vector/`: لوگوهای SVG با نوشته‌های تبدیل‌شده به مسیر وکتور
- `raster/`: خروجی‌های PNG شفاف در اندازه‌های کاربردی
- `icons/`: فاوآیکون، Apple Touch Icon، آیکون‌های PWA و App Icon
- `preview/`: Brand Board و پیش‌نمایش‌های سریع
- `docs/RYTHM-Brand-Guidelines-v1.0.pdf`: راهنمای کامل استفاده

## رنگ‌های برند

- Authority Navy: `#0B1220`
- Governance Indigo: `#6472E8`
- Decision Cyan: `#4BC6D8`
- System Cloud: `#F5F7FB`
- Operational Slate: `#667085`

## قواعد سریع

- نسخهٔ اصلی روی زمینهٔ روشن استفاده شود.
- روی زمینهٔ تیره، فقط نسخهٔ inverse استفاده شود.
- رنگ Cyan برای نقطهٔ تصمیم و سیگنال کنترل‌شده رزرو شده است.
- لوگو کشیده، چرخانده، سایه‌دار یا با فونت بازنویسی نشود.
- حداقل عرض لوگوی افقی در وب ۱۸۰ پیکسل و حداقل اندازهٔ نشان مستقل ۲۰ پیکسل است.
- برای navbar از نسخهٔ compact موجود در بسته استفاده شود.

## تایپوگرافی پیشنهادی

- UI و بازاریابی: Inter
- داده‌های فنی، شناسه‌ها و traceability: Geist Mono
- نوشتهٔ داخل فایل لوگو outline شده و به نصب فونت وابسته نیست.
