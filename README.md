# RYTHM Company OS

RYTHM is an AI-native Company Operating System for governed multi-agent operations, organizational memory, executive decision support, meetings, approvals, auditability, and human oversight.

## Status

Foundation and B-001 Executive Orchestrator specifications are complete. Runtime implementation is starting with the Company Core and Executive Command Center.

## Core principles

- Human authority over consequential actions
- Explainable and auditable decisions
- Shared, versioned organizational memory
- Least-privilege agent permissions
- Approval gates for external or destructive actions
- Continuous evaluation and controlled learning

## Initial stack

- Next.js / TypeScript
- Supabase / PostgreSQL
- Vercel
- OpenAI API
- GitHub Actions

## Local development

```bash
npm install
cp .env.example .env.local
npm run dev
```

Open `http://localhost:3000`.
